# Square Eyes Movies

SIte allowing for the purchase of movies fetched from Square Eyes API

## Description

Takes API-Data from Noroff Square Eyes API, adds them to the DOM through JavaScript to make the Square Eyes site.
This site shows an assortment of movies, filterable by genre, and with a search bar.
These movies can then be added to a cart and a simulated checkout allows for "purchase" of whatever movies get added to the cart.

## Built With

- HTML
- CSS
- JavaScript
